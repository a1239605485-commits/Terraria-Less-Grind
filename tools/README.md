## 📖 概述

### 什么是 TEFPkg-Tool

TEFPkg-Tool 是一个命令行工具，用于将目录中的文件打包成 TEF 包 (`.tefpkg`) 格式。它专为 TEFKernel 设计，能够自动识别包类型（Plugin/Module/ModLoader），并按照 TEFKernel 的规范组织文件。

### 核心特性

| 特性                | 说明                                  |
|:--------------------|:--------------------------------------|
| **🔍 自动类型检测** | 自动识别 Plugin/Module/ModLoader 类型 |
| **📋 文件列表生成** | 自动生成文件索引，支持按 ID 引用      |
| **🗜️ 灵活压缩**     | 支持 LZ4/LZ4HC 压缩，可配置文件级规则 |
| **🔐 包签名**       | 支持 SipHash 签名验证                 |
| **🚫 文件排除**     | 支持通配符排除不需要打包的文件        |
| **🏗️ 多平台支持**   | 自动处理多平台库文件命名              |

### 支持的文件类型

工具会自动识别以下包类型：

| 包类型     | 检测规则                    | 用途         |
|:-----------|:----------------------------|:-------------|
| **Plugin** | 目录中存在 `libplugin.*.so` | 插件包       |
| **Module** | 目录中存在 `libmodule.*.so` | 模块包       |
| **Loader** | 目录中存在 `libloader.*.so` | ModLoader 包 |

## 🚀 快速开始

### 安装与编译

```bash
# 克隆仓库
git clone https://github.com/eternalfuture-e38299/TEFPkg-Tool.git
cd TEFPkg-Tool

# 编译
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make

# 安装到系统路径 (可选)
sudo make install
```

### 基本使用

```bash
# 查看帮助
./tefpkg_tool

# 基本打包命令
./tefpkg_tool build ./source_dir ./output.tefpkg 0x12345678
```

## 📚 命令参考

### list - 列出目录文件

列出指定目录中的所有文件及其分配的 ID。

```bash
./tefpkg_tool list <dir> [exclude...]
```

**参数说明：**

| 参数           | 说明                         |
|:---------------|:-----------------------------|
| `<dir>`        | 要列出的目录路径             |
| `[exclude...]` | 可选的排除模式（支持通配符） |

**示例：**

```bash
# 列出 src 目录中的所有文件
./tefpkg_tool list ./src

# 排除临时文件和缓存目录
./tefpkg_tool list ./src "*.tmp" "cache/*"
```

**输出示例：**

```
File list for directory: ./src
Total files: 15
------------------------------------------------------------
ID    Path
------------------------------------------------------------
2     libplugin.android.arm64.so
3     libplugin.android.arm.so
4     libplugin.linux.x64.so
...
```

### tomacro - 生成 C 宏定义

将目录文件列表转换为 C 语言宏定义头文件，方便在代码中引用文件 ID。

```bash
./tefpkg_tool tomacro <dir> <output.h> [exclude...]
```

**参数说明：**

| 参数           | 说明             |
|:---------------|:-----------------|
| `<dir>`        | 源目录路径       |
| `<output.h>`   | 输出的头文件路径 |
| `[exclude...]` | 可选的排除模式   |

**示例：**

```bash
# 生成文件 ID 宏定义
./tefpkg_tool tomacro ./src ./file_ids.h "*.tmp"
```

**输出示例 (`file_ids.h`)：**

```c
/**
 * Auto-generated file ID macros
 * Generated from directory: ./src
 * DO NOT EDIT THIS FILE DIRECTLY
 */

#pragma once

#define FILE_ID_LIBPLUGIN_ANDROID_ARM64_SO     2  // libplugin.android.arm64.so
#define FILE_ID_LIBPLUGIN_ANDROID_ARM_SO       3  // libplugin.android.arm.so
#define FILE_ID_LIBPLUGIN_LINUX_X64_SO         4  // libplugin.linux.x64.so

// Total files: 15
```

### genkey - 生成密钥文件

生成 SipHash 密钥文件，用于包签名。

```bash
./tefpkg_tool genkey <author> <org> <loc> <output>
```

**参数说明：**

| 参数       | 说明             |
|:-----------|:-----------------|
| `<author>` | 作者名称         |
| `<org>`    | 组织名称         |
| `<loc>`    | 位置信息         |
| `<output>` | 输出密钥文件路径 |

**示例：**

```bash
# 生成密钥文件
./tefpkg_tool genkey "TEFKernel Team" "TEFKernel" "Earth" ./key.bin
```

### fingerprint - 生成指纹

从密钥文件生成指纹，用于包签名验证。

```bash
./tefpkg_tool fingerprint <key_file> [seed]
```

**参数说明：**

| 参数         | 说明                   |
|:-------------|:-----------------------|
| `<key_file>` | 密钥文件路径           |
| `[seed]`     | 种子值（可选，默认 0） |

**示例：**

```bash
# 生成指纹（使用默认种子）
./tefpkg_tool fingerprint ./key.bin

# 使用自定义种子
./tefpkg_tool fingerprint ./key.bin 0x12345678
```

**输出示例：**

```
Generating fingerprint from key file: ./key.bin
Seed: 0x0
Fingerprint: 0xABCDEF1234567890
```

### build - 打包 TEF 包

将目录打包成 `.tefpkg` 文件，这是最常用的命令。

```bash
./tefpkg_tool build <dir> <output> [fingerprint] [options]
```

**参数说明：**

| 参数            | 说明                        |
|:----------------|:----------------------------|
| `<dir>`         | 源目录路径                  |
| `<output>`      | 输出 `.tefpkg` 文件路径     |
| `[fingerprint]` | 指纹值（默认为 `0x114514`） |

**选项：**

| 选项                      | 说明                         |
|:--------------------------|:-----------------------------|
| `-e, --exclude <pattern>` | 排除匹配的文件（可多次使用） |
| `-c, --compress <json>`   | 压缩配置文件路径             |
| `-n, --no-file-list`      | 不生成文件列表（默认生成）   |

**示例：**

```bash
# 基础打包
./tefpkg_tool build ./src ./output.tefpkg 0x12345678

# 带排除规则
./tefpkg_tool build ./src ./output.tefpkg 0x12345678 -e "*.tmp" -e "cache/*"

# 使用压缩配置
./tefpkg_tool build ./src ./output.tefpkg 0x12345678 -c compress.json

# 不生成文件列表（减小包体积）
./tefpkg_tool build ./src ./output.tefpkg 0x12345678 -n
```

## 📝 配置文件

### 压缩配置 JSON

通过 JSON 配置文件，可以为不同文件指定不同的压缩策略。

**文件格式：**

```json
{
    "*.png": {
        "mode": "lz4hc",
        "level": 9
    },
    "*.mp3": {
        "mode": "none"
    },
    "libplugin.*.so": {
        "mode": "lz4",
        "level": 1
    },
    "assets/": {
        "mode": "lz4hc",
        "level": 9
    }
}
```

**配置项说明：**

| 字段    | 类型   | 说明                             |
|:--------|:-------|:---------------------------------|
| `mode`  | string | 压缩模式：`none`, `lz4`, `lz4hc` |
| `level` | int    | 压缩等级：1-9（仅对 lz4hc 有效） |

**匹配规则（优先级从高到低）：**

1. **精确匹配**：完整路径精确匹配
2. **通配符匹配**：`*` 和 `?` 通配符
3. **目录前缀匹配**：以 `/` 结尾的目录模式
4. **扩展名匹配**：`.png`、`.mp3` 等
5. **默认值**：`lz4` 等级 1

**示例：**

```bash
# 使用压缩配置文件打包
./tefpkg_tool build ./src ./output.tefpkg 0x12345678 -c compress.json
```

### 文件排除规则

`-e` 选项支持通配符排除：

| 模式      | 说明                         |
|:----------|:-----------------------------|
| `*.tmp`   | 排除所有 `.tmp` 文件         |
| `cache/*` | 排除 `cache/` 目录下所有文件 |
| `*.log`   | 排除所有 `.log` 文件         |

**示例：**

```bash
# 排除多种文件类型
./tefpkg_tool build ./src ./output.tefpkg 0x12345678 \
    -e "*.tmp" \
    -e "*.log" \
    -e "cache/*" \
    -e ".*"  # 排除隐藏文件
```

## 💡 完整示例

### 打包插件

**目录结构：**

```
my_plugin/
├── libplugin.android.arm64.so
├── libplugin.android.arm.so
├── libplugin.linux.x64.so
├── libplugin.windows.x64.dll
├── config.json
└── icon.png
```

**打包命令：**

```bash
# 1. 生成密钥（可选）
./tefpkg_tool genkey "MyTeam" "MyOrg" "World" ./key.bin

# 2. 生成指纹
FINGERPRINT=$(./tefpkg_tool fingerprint ./key.bin 0x114514 | grep -o '0x[A-F0-9]*')

# 3. 创建压缩配置
cat > compress.json << EOF
{
    "*.png": {"mode": "lz4hc", "level": 9},
    "*.json": {"mode": "lz4", "level": 1},
    "libplugin.*.so": {"mode": "lz4", "level": 1}
}
EOF

# 4. 打包
./tefpkg_tool build ./my_plugin ./my_plugin.tefpkg ${FINGERPRINT} -c compress.json
```

### 打包模块

**目录结构：**

```
my_module/
├── libmodule.android.arm64.so
├── libmodule.android.arm.so
├── libmodule.linux.x64.so
├── textures/
│   ├── grass.png
│   └── stone.png
└── sounds/
    └── ambient.mp3
```

**打包命令：**

```bash
# 压缩配置（音频和图片用不同策略）
cat > compress.json << EOF
{
    "textures/*.png": {"mode": "lz4hc", "level": 9},
    "sounds/*.mp3": {"mode": "none"},
    "*.so": {"mode": "lz4", "level": 1}
}
EOF

# 打包
./tefpkg_tool build ./my_module ./my_module.tefpkg 0x12345678 -c compress.json
```

### 打包 ModLoader

**目录结构：**

```
my_modloader/
├── libloader.android.arm64.so
├── libloader.android.arm.so
├── libloader.linux.x64.so
├── libloader.windows.x64.dll
├── default_config.json
└── builtin_mods/
    ├── mod1.tefpkg
    └── mod2.tefpkg
```

**打包命令：**

```bash
# 排除内置 Mod（它们会被单独打包）
./tefpkg_tool build ./my_modloader ./my_modloader.tefpkg 0x12345678 \
    -e "builtin_mods/*"
```

## ⚠️ 注意事项

### 文件命名规范

| 包类型     | 命名格式                          | 示例                         |
|:-----------|:----------------------------------|:-----------------------------|
| **Plugin** | `libplugin.{system}.{arch}.{ext}` | `libplugin.android.arm64.so` |
| **Module** | `libmodule.{system}.{arch}.{ext}` | `libmodule.linux.x64.so`     |
| **Loader** | `libloader.{system}.{arch}.{ext}` | `loader.windows.x64.dll`     |

### 支持的平台架构

| 系统    | 架构       | 后缀   |
|:--------|:-----------|:-------|
| Android | arm64, arm | .so    |
| Linux   | x64, x86   | .so    |
| Windows | x64, x86   | .dll   |
| macOS   | arm64, x64 | .dylib |

### 文件 ID 分配

| ID 范围 | 用途                   |
|:--------|:-----------------------|
| 0       | 文件列表（自动分配）   |
| 1-11    | 固定库文件（自动分配） |
| 12+     | 用户文件（按字母顺序） |

### 常见问题

**Q: 如何指定包类型？**

A: 工具会自动检测。确保目录中包含对应命名规范的库文件。

**Q: 没有库文件怎么办？**

A: 工具会检测到无库文件，然后按通用包类型处理，所有文件 ID 从 1 开始。

**Q: 如何减小包体积？**

A: 使用 `-n` 选项不生成文件列表，并配置合理的压缩策略。

**Q: 打包后如何验证？**

A: 工具会自动执行 `tefpkg_verify_pkg` 和 `tefpkg_verify_signature` 验证。
